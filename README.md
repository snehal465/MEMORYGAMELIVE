# 🎮 MemoryGameLive

A simple and fun **card-flip memory game** built with HTML, CSS, and JavaScript.  
Test your memory by flipping cards to find matching pairs!

## ✨ Features
- 🃏 **9 cards** with **4 matching pairs** and 1 extra card
- 🔄 **Restart option** to play again anytime
- 🎨 Clean and responsive design
- ⚡ Lightweight and fast — runs directly in the browser

## 🚀 How to Play
1. Click on a card to flip it.
2. Try to find its matching pair.
3. If two cards match, they stay flipped.
4. If they don’t match, they flip back.
5. Continue until all pairs are matched.
6. Use the **Restart button** to start a new game.

## 🛠️ Technologies Used
- **HTML5** for structure
- **CSS3** for styling
- **JavaScript (ES6)** for game logic
